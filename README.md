# 📈 Stock Portfolio Tracker

A beginner-friendly Python application that calculates the total investment value of a stock portfolio using manually defined stock prices.

## 📌 Project Overview

The Stock Portfolio Tracker allows users to enter stock names and quantities, calculates individual stock investments, and displays the total value of their portfolio.

It also provides an option to save portfolio details in a CSV file for future reference.

## ✨ Features

- Displays available stocks and their prices.
- Accepts stock names and quantities from users.
- Calculates investment value for each stock.
- Calculates the total portfolio investment.
- Handles invalid stock names and quantities.
- Displays a portfolio summary.
- Saves portfolio details in a CSV file.

## 🛠️ Technologies Used

- Python 3
- Dictionaries
- Lists
- Loops and Conditional Statements
- Input/Output Operations
- File Handling
- CSV Module

## 🚀 How to Run

**1. Clone the repository**

```bash

```

**2. Navigate to the project folder**

```bash
cd StockPortfolioTracker
```

**3. Run the Python program**

```bash
python stock_tracker.py
```
